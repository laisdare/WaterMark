# WaterMark
Projeto desenvolvido durante minha atuação na WECARE HOSTING para aplicar marca d'água nas imagens de forma mais rápida e padronizada, automatizando o fluxo.

Antes, a aplicação da marca d'água era feita de forma manualmente, imagem por imagem. Essa aplicação permite reduzir etapas manuais e padronizar o processo de aplicação da marca d'água.

A aplicação permite:
Selecionar uma pasta com as imagens;
Escolher quais fotos serão processadas;
Comparar as opções de marca d'água;
Aplicar a marca automaticamente, mantendo tamanho e posicionamento padronizados;
Processar várias imagens em sequência;
Baixar o resultado final em um único arquivo ZIP.

Foi um projeto que me permitiu transformar uma necessidade operacional em uma solução prática usando desenvolvimento WEB.
